# Logo miniWMS

Znak to paleta z trzema kartonami, w kolorach motywu „mięta” z aplikacji
(`#14533f`, `#2e8b66`, `#9fe0bf`). Napis „miniWMS” jest złożony fontem Manrope
(`warehouse/static/warehouse/fonts/`, licencja SIL OFL).
