Import stanów początkowych

Wgraj plik CSV lub XLSX. Każdy wiersz = jedna paleta (HU). Obsługiwane kolumny:

  • HU — numer palety (jeśli pusty, zostanie wygenerowany)
  • REF — indeks materiału (wymagany; materiał powstanie automatycznie)
  • nazwa — nazwa materiału
  • ilosc — opcjonalna; puste = 0 (uzupełnisz ręcznie przez „Korekta ilości”)
  • lokalizacja — kod miejsca; Przyjęcia/-/puste = strefa przyjęć
  • partia, data ważności — opcjonalne (- = brak)
